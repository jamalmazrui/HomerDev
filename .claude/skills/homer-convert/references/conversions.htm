Conversions by format pair

EdSharp’s Import and Export tables, which have been used for years, hold a tested command for each pair. The Pandoc ones are below, with the source as in and the target as out; -s makes a standalone document. Pairs that run a helper (any2htm, pdf2md, sheet2md, mdx2htm, mdx2docx) are EdSharp scripts in its configs/convert folder; 2htm or inixVert does the same work outside EdSharp.

Two differences from a Homer document: these pairs read and write GitHub’s Markdown (gfm), where a Homer document uses Pandoc’s own (-f markdown); and they accept .html as well as .htm, where a Homer program writes .htm.
